# Recorrido 3D futuro

Esta carpeta reserva la futura experiencia inmersiva sin cargar dependencias 3D en la versión actual.

Cuando el recorrido esté disponible:

1. Instalar Three.js, React Three Fiber y Drei.
2. Incorporar un modelo GLB optimizado y comprimido para web.
3. Cargar el visor de forma diferida únicamente después de que la persona pulse “Iniciar recorrido”.
4. Mantener una alternativa accesible con fotografías y texto, y respetar `prefers-reduced-motion`.
